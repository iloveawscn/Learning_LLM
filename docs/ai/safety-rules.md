# Safety Rules

## 密钥和隐私规则

- 不读取、不输出、不保存 API Key、Cookie、Token、密码、SSH Key
- 不把敏感信息写入项目文档
- .env 文件内容绝对不可读取或输出

## 数据库规则

- 本项目无数据库，但涉及文件读取时需谨慎

## 系统配置规则

- 修改系统级配置前必须给出备份和回滚方案

## Git 安全规则

- 不执行 `git push --force`
- 不执行 `git reset --hard`
- 不删除分支

## 破坏性操作规则

- 不执行 `rm -rf` 或类似删除命令
- 文件删除前必须确认不再需要
